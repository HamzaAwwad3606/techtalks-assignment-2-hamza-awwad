# Six-Month Learning Roadmap

## Roadmap Strategy

This roadmap is based on the recurring skills identified in the
market research. The highest priority is given to JavaScript/TypeScript,
React, Node.js, databases, and API development because these skills
appeared most frequently across the researched job listings.

Less frequently requested technologies will be considered later rather
than being prioritized during the core learning period.

## Six-Month Roadmap

| Month | Focus | Skills / Technologies | Main Goal |
|---|---|---|---|
| Month 1 | JavaScript Fundamentals (may take them in uni) | JavaScript, HTML, CSS, Git | Build solid web development foundations |
| Month 2 | TypeScript + Frontend | TypeScript, React fundamentals | Build typed React applications |
| Month 3 | React Development | React, APIs, Git | Build complete frontend applications |
| Month 4 | Backend Development | Node.js, Express, APIs | Build backend services and REST APIs |
| Month 5 | Databases + Full Stack | SQL, databases, Node.js, React | Connect frontend, backend, and database |
| Month 6 | Full-Stack Project | React, TypeScript, Node.js, APIs, SQL, Docker | Build and deploy a complete full-stack application |

## Month 1 — JavaScript Fundamentals

### Skills
- JavaScript
- HTML
- CSS
- Git

### Goals
- Learn JavaScript fundamentals
- Understand DOM manipulation
- Build responsive web pages
- Learn Git and GitHub
- Build small JavaScript projects

## Month 2 — TypeScript and React Fundamentals

### Skills
- TypeScript
- React
- Components
- Props
- State
- Hooks

### Goals
- Understand TypeScript fundamentals
- Learn React components
- Build reusable UI components
- Create a small React application

## Month 3 — React and API Integration

### Skills
- React
- TypeScript
- REST APIs
- API integration
- Git

### Goals
- Build larger React applications
- Work with external APIs
- Handle loading and error states
- Create responsive interfaces

## Month 4 — Backend Development

### Skills
- Node.js
- Express
- REST APIs
- JavaScript / TypeScript

### Goals
- Understand backend development
- Build REST APIs

### Skills
- SQL
- Database design
- Node.js
- React
- REST APIs

### Goals

- Write SQL queries

## Month 6 — Full-Stack Project

### Skills
- React
- TypeScript
- Node.js
- REST APIs
- SQL
- Git
- Docker

### Goals

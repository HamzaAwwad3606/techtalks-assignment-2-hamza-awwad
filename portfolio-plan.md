# Portfolio Plan

## Portfolio Strategy

The portfolio projects were selected based on the recurring skills,
technologies, and responsibilities identified in the researched
Full Stack Developer job listings.

The projects focus on demonstrating the highest-priority skills found
in the research, including JavaScript/TypeScript, React, Node.js,
database development, and API development. Docker is also included
where appropriate because it appeared in multiple listings.

---

## Project 1 — Sports News & Match Platform

### Description

A full-stack web application that provides sports news, match
information, team information, and statistics. Users can browse
sports news, view upcoming and completed matches, search for content,
and save articles.

The application will use an external sports API to retrieve live or
updated sports data and a backend API to manage application-specific
data.

### Technologies

- React
- TypeScript
- Node.js
- Express
- REST APIs
- SQL
- Git

### Key Features

- Browse sports news articles
- View upcoming and completed matches
- View teams and player information
- Search and filter news and matches
- User registration and login
- Save/bookmark articles
- External sports API integration
- Admin dashboard for managing news articles
- Create, edit, and delete articles
- Responsive design

### Skills Demonstrated

- React frontend development
- TypeScript
- Node.js backend development
- REST API development and integration
- SQL database management
- CRUD operations
- Authentication
- Git and GitHub

### Connection to Job Market

This project demonstrates several of the core technologies identified
in the job research, particularly React, TypeScript, Node.js, APIs,
and database development. It also reflects real-world responsibilities
such as developing web applications, integrating APIs, managing data,
and building user interfaces.

---

## Project 2 — Restaurant Ordering & Reservation System

### Description

A full-stack restaurant platform that allows customers to browse a
restaurant menu, place orders, and make reservations. An admin
dashboard allows restaurant staff to manage menu items, orders, and
reservations.

### Technologies

- React
- TypeScript
- Node.js
- Express
- REST APIs
- SQL
- Git

### Key Features

- Browse and search the restaurant menu
- Filter dishes by category
- User registration and login
- Shopping cart
- Place food orders
- Make restaurant reservations
- View order history
- Manage user accounts
- Admin dashboard
- Add, edit, and delete menu items
- Manage orders and reservations
- Database integration
- Responsive design

### Skills Demonstrated

- React
- TypeScript
- Node.js
- REST API development
- SQL and database design
- CRUD operations
- Authentication and authorization
- Frontend and backend integration
- Git and GitHub

### Connection to Job Market

This project demonstrates the core full-stack skills identified in
the research. It combines React on the frontend with Node.js and REST
APIs on the backend and uses SQL to manage application data. The
ordering, reservation, and administration features also demonstrate
real-world application development and CRUD responsibilities.

---

## Portfolio Conclusion

These two projects were selected to demonstrate the most frequently
requested skills identified in the job-market research. Together,
they provide experience in frontend development, backend development,
API integration, database management, authentication, CRUD operations,
and deployment-related technologies.

The projects also represent different types of real-world
applications rather than repeating the same type of project. The
Sports News & Match Platform focuses on external API integration and
data, and the Restaurant Ordering & Reservation System focuses on
transactions and CRUD operations.
